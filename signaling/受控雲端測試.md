# v1.6.1 單一 Worker 受控測試（Windows）

本文件取代先前「需要自訂網域／獨立候選主機」方案。不必購買網域：使用既有 `bio-city-v161-signaling` 的帳戶 `*.workers.dev`，同一 Worker 提供候選頁、白名單資源與 `/rooms`、WebSocket。現階段僅完成開發驗證；尚未由本 PR 部署、開啟網址或完成真人雲端驗收。既有 Room、RateGate、RATE_SECRET 不重建／重設，正式 main、Pages、GTM／GA4 不變。

## 本機準備（沒有雲端變更）

Windows 需 Node.js 22 以上、PowerShell 5.1 以上，且既有 Wrangler 登入對應帳戶。從 PR #37 核對最新候選 SHA 與 CI（不得使用較早提交的成功代替）。以下把資料解壓至暫存資料夾：

```powershell
$sha = '填入PR已驗證的完整40位SHA'
if ($sha -notmatch '^[0-9a-f]{40}$') { throw '請填入完整 SHA' }
$root = Join-Path $env:TEMP ('bio-city-v161-' + $sha)
New-Item -ItemType Directory -Force $root | Out-Null
Invoke-WebRequest "https://github.com/squallorc-dot/fun/archive/$sha.zip" -OutFile "$root\source.zip"
Expand-Archive "$root\source.zip" -DestinationPath $root
Set-Location (Join-Path $root ("fun-" + $sha))
npx.cmd --yes wrangler@4.156.0 --version
```

從 Cloudflare 現有 Worker 畫面確認它原本所屬的免費帳戶子網域，**先不要開啟網址**。下列填入該 Worker 的完整 origin，不帶路徑，不能是 Preview URL；這不是新建 Worker，也不是購買自訂網域：

```powershell
$origin = 'https://bio-city-v161-signaling.您的帳戶子網域.workers.dev'
node scripts/prepare-controlled-test-v161.mjs $origin
if ($LASTEXITCODE -ne 0) { throw '設定失敗' }
node scripts/build-controlled-assets-v161.mjs
if ($LASTEXITCODE -ne 0) { throw '打包失敗' }
Get-Content signaling/worker/wrangler.toml
npx.cmd --yes wrangler@4.156.0 deploy --dry-run --config signaling/worker/wrangler.toml --outdir "$root\dry-run"
if ($LASTEXITCODE -ne 0) { throw '乾跑失敗，不可部署' }
```

檢查：名稱仍是既有 Worker；`workers_dev=false`、`preview_urls=false`、`TEST_ENABLED="false"`；無 route／custom domain；`assets.run_worker_first=true`、HTML 自動轉址關閉，ASSETS 指向只含白名單的 `candidate-assets`；ALLOWED_ORIGINS 恰為上述 origin。Room／RateGate 的綁定及兩個既有 migration 不變。新測試以單一 HTTPS／WSS origin 運作；Worker 會在回傳候選頁時再次設定同源 endpoint。

## 以下每一步均須另行取得使用者明確核准

**目前未授權執行此節。** `secret put`、部署與開啟 workers.dev 都會改變 Cloudflare。不要讓 AI 自動執行，也不要把 Token、IP 或 secret 貼在聊天、PR 或日誌。不要啟用付費方案。

1. 使用者核准後，在自己已登入的 Windows 終端確認帳戶與現有 Worker 版本、密鑰名稱及免費額度／用量警示。用 `npx.cmd --yes wrangler@4.156.0 deployments list --config signaling/worker/wrangler.toml` 記錄舊版；`secret list` 只列名稱，不讀值。若已存在名為 TEST_ENABLED 的 secret，先停止：此版以非秘密的 vars 開關控制，不能未經核准刪除或覆蓋既有 secret。
2. 使用者核准後，私下取得兩裝置實際出口 IPv4／IPv6（各裝置可能不同；手機請同 Wi-Fi 並留意 IPv6、VPN／Private Relay）。只在本機輸入，逗號分隔、IPv6 不加方括號、最多 16 個地址。設定額外測試 secret，**不動 RATE_SECRET**。不要啟用終端 transcript 或截圖：

```powershell
$ips = Read-Host '輸入兩裝置實際出口 IP（逗號分隔）' -AsSecureString
$plain = [System.Net.NetworkCredential]::new('', $ips).Password
$plain | npx.cmd --yes wrangler@4.156.0 secret put TEST_ALLOWED_IPS --config signaling/worker/wrangler.toml
if ($LASTEXITCODE -ne 0) { throw '設定失敗' }
$plain = $null; $ips = $null
$until = [DateTimeOffset]::UtcNow.AddMinutes(30).ToUnixTimeSeconds().ToString()
$until | npx.cmd --yes wrangler@4.156.0 secret put TEST_EXPIRES_AT --config signaling/worker/wrangler.toml
if ($LASTEXITCODE -ne 0) { throw '設定失敗' }
```

3. 使用者確認候選 SHA、乾跑、來源名單與 30 分鐘時限後，再明確核准部署並短時開啟 **同一 Worker** 的 workers.dev。預設檔案保持關閉，只有在這個本機副本執行：

```powershell
$config = 'signaling/worker/wrangler.toml'
$text = Get-Content $config -Raw
$text = $text.Replace('workers_dev = false', 'workers_dev = true').Replace('TEST_ENABLED = "false"', 'TEST_ENABLED = "true"')
[System.IO.File]::WriteAllText((Join-Path $PWD $config), $text, [System.Text.UTF8Encoding]::new($false))
npx.cmd --yes wrangler@4.156.0 deploy --dry-run --config $config --outdir "$root\dry-run-enabled"
if ($LASTEXITCODE -ne 0) { throw '乾跑失敗' }
# 在使用者再次確認上述差異後才執行下一行：
npx.cmd --yes wrangler@4.156.0 deploy --config $config
if ($LASTEXITCODE -ne 0) { throw '部署失敗，保持／恢復入口關閉並檢查' }
```

此操作不是 Pages 正式發布。Preview URL 仍是 false，不使用 Worker-level Access（會影響 WebSocket upgrade），不新增 STUN／TURN。若免費帳戶或平台拒絕任何設定，保存不含秘密的錯誤並停止，不升級付費。

## 兩台裝置最簡單的驗收

1. 兩台同 Wi-Fi，先在 Windows 打開 `$origin/arcade/friends/`。手機掃房主顯示的 QR 或開分享連結；雙方選角、選遊戲、準備、開始。QR／fragment 應在讀取後從網址移除。
2. G05 桌球／排球雙方移動、有效回球與得分；同房間切 G01、G02、G06。G02 看雙方 600×600 戰場、三波／Boss、技能與自然受傷救援；G06 看各自視角、三圈九檢查點及一致結果。回大廳、取消準備、重選角、重賽都測一次。挑戰頁可從大廳連結開啟，G03／G04 成績維持自報標示。
3. 測 OST／音效、繁中／日文、手機直橫向、安全區和控制配置。短暫訊號中斷但 RTC 正常不應停局；RTC 中斷後舊局作廢，雙方同意重連才在原房間開始新局。Windows Chrome／Edge、Windows＋Android、Windows＋iPhone、iPhone＋Android 全列待人工，不可只用桌面模擬當真機通過。
4. 真實 Cloudflare 必測：不允許來源對 HTML／JS／CSS／圖片／音訊及 API／WS 均 403；沒有 Origin 的允許導航 GET 可載入；錯誤 Origin 的 POST／WS 仍拒絕；過期／關閉後新請求 403；來源限流 429，並觀察免費用量警示。需驗證 CF-Connecting-IP 確為 Cloudflare ingress 可信值，客戶端不能藉 X-Forwarded-For／Cookie 繞過。手機不同出口的拒絕應先核對實際網路，不放寬到萬用清單。不要輸出建房 response（包含憑證）、SDP、ICE 或真實 IP。無 STUN／TURN 不保證跨網路。

## 關閉與回復（需使用者核准）

兩端先離房、關閉頁面，再在同一本機副本關閉開關和 workers.dev，檢查 preview、額外 route 仍關閉：

```powershell
$text = Get-Content $config -Raw
$text = $text.Replace('workers_dev = true', 'workers_dev = false').Replace('TEST_ENABLED = "true"', 'TEST_ENABLED = "false"')
[System.IO.File]::WriteAllText((Join-Path $PWD $config), $text, [System.Text.UTF8Encoding]::new($false))
npx.cmd --yes wrangler@4.156.0 deploy --config $config
if ($LASTEXITCODE -ne 0) { throw '關閉失敗：立即在 Cloudflare 停用入口並確認狀態' }
```

驗證外部不能新建房或載入頁面；檢查沒有手動 route／Preview 等額外入口。本門禁預設拒絕、到期自動拒絕**新 HTTP／WS**；不會主動中止既有 RTC／WS，不能把它稱為即時撤銷。回退舊 Worker 前必須先關閉 workers.dev／所有 routes，因為舊版可能沒有門禁。不要刪除 DO、migration 或重設 RATE_SECRET。

## 安全與工程狀態

所有靜態請求由 `run_worker_first=true` 先檢查啟用、期限與地址，再檢查明確白名單，最後才呼叫 ASSETS；不存在資產優先旁路。私有目錄、設定、文件、測試結果與 Git 不入包且 Worker 拒絕提供。候選頁與資源 `no-store`，CSP 僅同源（允許既有行內樣式／腳本、data/blob 圖片、同源 iframe），不載入正式 GTM／GA4。請以新的測試分頁驗證，勿安裝 service worker 或沿用非候選頁快取。

本機 Workerd 可以驗證打包、路由、CSP 和模擬來源門禁，**不能**替代真正 Cloudflare 的 ingress、免費額度、DO hibernation／alarm、平台資產路由和真人驗收。待雲端部分如有不相容，先保存具體證據，再評估最小替代，不要求先購買網域。

## 手機 IP 不固定時的短時測試（2026-10-31）

如果 Windows 能開啟（200）但手機仍被 `{"error":"unavailable"}`（403）拒絕，為省去反覆取得 IPv4／IPv6，可在使用者明確授權的**既有測試 Worker** 上，選擇一次性 `TEST_OPEN_WINDOW="true"`（本地設定檔中 `[vars]`）。

嚴格限制：

- `TEST_ENABLED` 仍須為 `true`；`TEST_EXPIRES_AT` 必須是**現在起不超過 15 分鐘**的十位 Unix 秒數，超過 15 分鐘會 fail-closed 403；過期立即拒絕新的 HTTP／WebSocket。
- 請求仍必須有 Cloudflare 可信 `CF-Connecting-IP`；HTML 僅限 `ALLOWED_ORIGINS` 相同 origin；API／WebSocket 保留 Origin 驗證、`RATE_SECRET`、RateGate、Room 雙憑證與房主允許。這不是私有網站：15 分鐘內任何網路可嘗試請求，需監看免費用量，不可用於正式公開服務。
- **預設 `TEST_OPEN_WINDOW="false"`**，不改既有 `TEST_ALLOWED_IPS`／`RATE_SECRET`；使用者確認後只可短時開啟，且必須在 Windows 上通過乾跑後部署，結束立即將 `workers_dev=false`、`TEST_ENABLED="false"`、`TEST_OPEN_WINDOW="false"` 回寫並重新部署。不要重新啟動試用或以無限到期日公開。
- Cloudflare 不會因 `TEST_EXPIRES_AT` 過期而主動斷開已建立的 WebRTC，測試後必須離房並關閉 Worker；正式 Pages main 在手機實機驗收之前維持不變。
