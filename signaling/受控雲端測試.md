# v1.6.1 受控雲端連線測試

狀態：程式和本機測試，不代表 Cloudflare 或手機已驗收。現有服務與 `RATE_SECRET` 不需重建或重設。此文件不授權部署、建立 DNS／route、開啟網址或變更正式網站；每項外部操作須由使用者另外確認。

## 入口與限制

Worker 預設 `workers_dev = false`、`preview_urls = false`，版本控制不包含 route。新門禁對每個新 HTTP 請求和 WebSocket upgrade 先檢查 `TEST_ENABLED=true`、未過期的 Unix 秒數 `TEST_EXPIRES_AT`、`TEST_ALLOWED_IPS` 精確地址清單（逗號分隔，最多 16 個 IPv4／IPv6），任一缺失或格式錯誤皆 403。之後仍檢查完整 Origin、HMAC 限流及房間憑證。以上只在 Cloudflare 正確提供可信 `CF-Connecting-IP` 且 Worker 不經不可信代理時成立，必須在真實 ingress 實測；本機模擬標頭不能證明這一點。請勿將真實 IP、secret、SDP、ICE、房間憑證寫入原始碼、PR、日誌或聊天。

開關和到期只阻擋新的請求／upgrade，**不會主動終止已建立的 WebSocket 或 RTC**。結束測試時兩端先離房並關閉頁面，再關閉入口；必要時由使用者在 Cloudflare 停用 route／Worker。這不是即時撤銷既有連線的機制。

目前沒有手機可安全存取的候選 HTTPS 網址，也沒有 Worker 公開入口；不能直接開始雙機測試。最小替代方案須先確認使用者控制且已有的網域、合法憑證、DNS 與費用：在獨立候選 hostname 上以可信 HTTPS 提供解壓後的靜態遊戲，候選頁前置 Cloudflare Access 僅允許測試者；另外在不同 hostname 建立受限 Worker route，Worker **本身不套用會阻擋 WebSocket upgrade 的 Access policy**，改由本門禁、來源 IP、有效期、Origin、房間憑證及限流保護。候選頁與 Worker 的部署及路由都需要另行授權；Cloudflare Access／Tunnel 免費額度、Access 登入跨兩台手機、邀請 fragment 和 WebSocket、`CF-Connecting-IP` 是否符合預期都尚未實證。若沒有合適網域或任何部分要求付費／不符合限制，停止並另行決定；不可用公開 Beta、未知 CA、自稱私有的隱藏網址或僅 CORS 取代。若手機使用 IPv6、行動網路或不同 NAT，先在各裝置以可信方式確認實際出口，再由使用者私下加入完整來源清單。

## Windows PowerShell：只準備本機資料

需 Windows 的 Node.js 22+、npm、已登入對應帳戶的 Wrangler 4.156.0。使用者應先核對 PR 最新候選 SHA 與 CI；以下 `$sha` 必須填入該次驗證的完整 SHA，而非分支名稱。官方 ZIP 不含 Git 驗證資訊；建議透過 GitHub 官方 PR／commit 網頁核對 SHA。以下不執行部署：

```powershell
$sha = '請填入PR最新且已驗證的完整40位SHA'
if ($sha -notmatch '^[0-9a-f]{40}$') { throw '請填入完整 SHA' }
$root = Join-Path $env:TEMP ('bio-city-v161-' + $sha)
New-Item -ItemType Directory -Force $root | Out-Null
Invoke-WebRequest "https://github.com/squallorc-dot/fun/archive/$sha.zip" -OutFile "$root\source.zip"
Expand-Archive "$root\source.zip" -DestinationPath $root
$src = Join-Path $root ("fun-" + $sha)
Set-Location $src
npx.cmd --yes wrangler@4.156.0 --version
Get-Content signaling/worker/wrangler.toml
```

確認名稱是 `bio-city-v161-signaling`、兩個開關都是 false，沒有 route／custom domain，綁定 `ROOMS`、`RATE_GATES` 及既有 migration。下列兩個 origin 必須是事先確認屬於使用者、可供手機可信存取的**完整 HTTPS origin**，不能帶路徑、帳密、查詢或片段。此步只改解壓資料夾，且禁止使用正式 GitHub Pages origin：

```powershell
$candidateOrigin = 'https://候選頁受控網域'
$signalOrigin = 'https://受控信號服務網域'
node scripts/prepare-controlled-test-v161.mjs $candidateOrigin $signalOrigin
if ($LASTEXITCODE -ne 0) { throw '候選設定失敗，請勿繼續' }
npx.cmd --yes wrangler@4.156.0 deploy --dry-run --config signaling/worker/wrangler.toml --outdir "$root\dry-run"
if ($LASTEXITCODE -ne 0) { throw '乾跑失敗，請勿繼續' }
```

腳本只配置候選 `arcade/friends/index.html` 的訊號 origin 與本機 `wrangler.toml` 的 `ALLOWED_ORIGINS`；不發布、建立網域、設定 secret 或修改 PR。候選靜態主機只應提供遊戲所需靜態檔案，絕不可公開 `signaling`、操作文件、設定檔、測試結果或憑證；必須驗證 G02 iframe、遊戲資源、音效、登入與邀請 fragment 正確。

## 僅於使用者逐步核准後執行

1. 比對 Cloudflare 帳戶、現有 Worker 與版本，記錄回退版本與目前設定；確認免費額度及候選頁、Worker route 的精確域名。不要重新建立 `Room`、`RateGate` 或設定 `RATE_SECRET`。
2. 確認來源安全與時限後，由使用者授權設定新測試 secret；`secret put` 會修改雲端，以下不是純本機操作。例子將網路出口清單以隱藏輸入送入 CLI，測試到期設 30 分鐘；勿開啟 PowerShell transcript、錄影或把結果貼到聊天。實際 IP 必須由使用者自行填入，IPv6 不加方括號。先保持關閉。

```powershell
# 此段會修改既有 Worker；只有取得使用者明確核准後才能執行。
$ips = Read-Host '輸入兩裝置實際出口 IP，逗號分隔' -AsSecureString
$plainIps = [System.Net.NetworkCredential]::new('', $ips).Password
$plainIps | npx.cmd --yes wrangler@4.156.0 secret put TEST_ALLOWED_IPS --config signaling/worker/wrangler.toml
if ($LASTEXITCODE -ne 0) { throw '設定失敗' }
$plainIps = $null; $ips = $null
$expires = [DateTimeOffset]::UtcNow.AddMinutes(30).ToUnixTimeSeconds().ToString()
$expires | npx.cmd --yes wrangler@4.156.0 secret put TEST_EXPIRES_AT --config signaling/worker/wrangler.toml
if ($LASTEXITCODE -ne 0) { throw '設定失敗' }
'false' | npx.cmd --yes wrangler@4.156.0 secret put TEST_ENABLED --config signaling/worker/wrangler.toml
if ($LASTEXITCODE -ne 0) { throw '設定失敗' }
```

3. 確認乾跑和待發布版本，另行核准後才可 `npx.cmd --yes wrangler@4.156.0 deploy --config signaling/worker/wrangler.toml`。先保持門禁關閉；部署時必須使用已確認的候選 Origin 且保留現有 `RATE_SECRET`。依帳戶實況確認部署不會意外修改現有綁定、密鑰或 route；不可自行建立新 Durable Object migration。
4. 只在入口設計、Cloudflare Access 測試及費用均已確認，且使用者另行核准後，設定受控候選頁、對應 Worker route，並由使用者執行 `'true' | npx.cmd --yes wrangler@4.156.0 secret put TEST_ENABLED --config signaling/worker/wrangler.toml`。以上都是雲端變更，先確認有效期尚未過、精確允許清單及所有入口。若任何一項無法確定，不要開啟。
5. 驗證未允許來源 403；允許的兩個不同來源或裝置可建房、WebSocket 自動交換與真正 RTC；錯誤 Origin、關閉／過期各為 403。觀察真實 Cloudflare 的來源標頭信任、限流及警示；不得輸出房間建立 response（含憑證）。用受控低流量確認限流，不要向正式分析平台發送測試事件。記錄結果時不記 IP、房間碼、token、SDP 或 ICE。當前全部**待雲端測試**。
6. 兩端先離房並關閉頁面；由使用者執行 `'false' | npx.cmd --yes wrangler@4.156.0 secret put TEST_ENABLED --config signaling/worker/wrangler.toml`，再關閉經授權的 route／候選入口，檢查無法新建房及連線。若發生意外，依事先記錄的 Worker 版本進行經授權回復；回復舊版本可能沒有本門禁，必須先關閉 route。不可刪除 DO 或重設 `RATE_SECRET`。
