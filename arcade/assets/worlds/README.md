# Bio-City 六款遊戲場景素材

這六張場景由內建 ImageGen 依本專案需求生成，轉為 WebP 後實際載入遊戲。它們是背景素材，平台、球網、彈珠靶、道路、檢查點與碰撞範圍均由遊戲程式繪製及計算。大廳六張遊戲圖卡取自正在執行的 Canvas。

共同提示要求：`stylized-concept`，Bio-City 精緻手繪 2.5D 城市場景，可信的材質、光源與空間，青綠／琥珀色調，清楚保留遊戲區域；不含文字、UI、人物、車輛或假障礙。

| 輸出檔案 | 場景提示與構圖要求 |
| --- | --- |
| `street.webp` | 16:9 戰鬥街道；建築位於上方 45%，下方 55% 為寬闊空地；適用橫向戰鬥視角。 |
| `defense.webp` | 方形、嚴格俯視的城市廣場；中央 80% 留空，建築與設備配置於周邊。 |
| `shaft.webp` | 2:3 深層維修井；管線和牆體位於兩側，中央 65% 留空，不畫平台；上、下延續可捲動空間。 |
| `laboratory.webp` | 5:6 俯視能源實驗室；中央約 85% 為空的深色操作區，機械位於邊緣；不畫球、靶或反彈器。 |
| `arena.webp` | 4:3、略高的正面運動場視角；上方觀眾席與屋頂，下方開放地面；不畫球網、球桌或場線。 |
| `race.webp` | 4:5 城市天際線；建築與天空集中於上方 38%，下方 62% 留給程式投影的道路；不畫車或道路。 |

原始 PNG 經 Pillow 縮至最長邊 1,280px，WebP 品質 82–84。遊戲依序載入使用中的場景，最多快取三張；載入失敗時保留原本可玩場地。

第 4B 批檢查：repo 中沒有這六張背景的原始 PNG、分層檔或更大尺寸版本。此批**沒有放大或重製這六張 WebP，也不宣稱補出原始細節**。實際尺寸依序為 street 1280×720、defense 1254×1254、shaft 853×1280、laboratory 1067×1280、arena 1280×960、race 1024×1280。程序地面、材質、陰影與遮擋保留為可編輯的 Canvas 原稿，能隨 backing store 繪製。`race` 的遠景只取原圖最上方 18%，排除高架交通與水面；遊戲道路仍由實際世界座標投影。`shaft` 採相鄰鏡像接合，避免直接重複非無縫圖片的接縫。

四種敵人由 `scripts/build-guardian-art.cjs --enemies-only` 的可編輯向量原稿產生 PNG 動畫圖集：孢子爬獸、鐵殼破壞者、裂隙幽靈與熵核巨獸。英雄原有圖集保留，每組 12 類動作、71 格。檔案雜湊記錄於 `../guardians/manifest.json`。

七英雄也保有同一支腳本中的可編輯向量動作原稿。第 4B 批新增 `guardians/2x/`：從 SVG 以 density 144 直接柵格化，單格 320×320、整張 2560×2880、每英雄 71 格，沒有以舊 PNG 插值。重製指令：`node scripts/build-guardian-art.cjs --high-resolution`，使用 Sharp 0.35.5 / libvips 8.18.7；實際版本應以產製機器 `require('sharp').versions` 核對。新圖集來源和原版相同，為本專案原創程序繪圖，未引入外部作品。尺寸、大小與 SHA-256 記於其 `manifest.json`。一般建置與執行不需要 Sharp。

G01 在 DPR > 1 才請求當前英雄的 2x 版本；其他遊戲及敵人沿用原版。最多一張 2x 加四張原版，圖集解碼像素上限 56.25 MiB。2x 下載或解碼失敗改讀原版，兩者都失敗仍顯示既有重試介面。這是同一向量細節的較高採樣版本，沒有新增角色設計或動作。背景與原版敵人在大螢幕／高 DPR 下仍可能受來源解析度限制，需另行取得更大的合法原圖或重新製作。
