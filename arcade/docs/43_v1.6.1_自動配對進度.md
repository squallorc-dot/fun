## 架構與實際測試

`signaling/worker/worker.mjs` 以 SQLite-backed Durable Object、hibernation WebSocket、房間過期 alarm 實作兩人訊號原型。房間識別碼不是憑證，兩個 256 位隨機憑證透過 WebSocket 首次訊息驗證，憑證雜湊存在房間儲存；訊號伺服器只轉送 offer／answer。`arcade/assets/friend-signaling.js` 沿用 `BioPeer.Link`，其現有做法是等待 ICE gathering 完成，將 candidates 內含於 SDP 一次交換，並非 trickle ICE；遊戲資料仍走原有 DataChannel，不使用 STUN／TURN。訊號模組尚未接入正式 UI。

- 本機 `wrangler dev --local` 使用 Workerd；`scripts/test-signaling-v161.mjs` 通過來源拒絕、建立房間、錯誤憑證拒絕、相同角色重複加入拒絕、雙方 WebSocket 訊號交換及房主離開清理。測試只輸出狀態，未記錄信號或憑證。
- 同腳本 `--rtc` 以兩個獨立 Chromium 程序測試自動配對，**未通過**：此 Cloud 執行環境本機 Chromium 產生 0 個 ICE candidates，結果為 `pairing-failed`／`peer-left`。沒有更改安全政策。GitHub Actions [41053292689](https://github.com/squallorc-dot/fun/actions/runs/41053292689) 對提交 `ab1aea7` 已用本機 Worker 及兩個獨立 Chromium 程序成功建立真正 DataChannel 並雙向傳輸；後續修改須以最新提交的結果為準。
- hibernation 在程式中使用 `acceptWebSocket` 與 attachment，但本機測試尚未證明真實 Cloudflare 休眠與喚醒。免費用量、雲端部署和網路条件均未驗收。

## 後續本機修正

- 未認證 socket 以 alarm 在 10 秒後清理；房主／來賓同角色競爭由 Durable Object 序列化處理，已增加模擬競爭與到期的 Node 測試及本機 Workerd 測試。訊號中斷後已連線的客戶端會清理現有連線。
- 目前仍無基於服務端來源的跨房間速率限制；瀏覽器 Origin 檢查不是存取控制，不應公開部署。

## 未完成與後續風險

4. 雲端計費能力、限制、真實 hibernation、IPv6／網路政策，Windows、iPhone、Android 真機同 LAN 均**待人工／雲端驗收**。沒有 STUN／TURN 不保證跨網路可連。

## 新好友介面與房間碼原型

- 新增尚未連接正式入口的 `arcade/friends/index.html`。初始只提供建立、加入、返回及語言選擇；保留既有遊戲 session／控制與音訊模組，隱藏手動 SDP 診斷欄位。G02 iframe 使用新頁面的同源路徑，原診斷頁路徑保持不變。
- 房間碼本身不授權入房：新請求須由已驗證房主明確同意，才向該來賓發送 10 秒有效的單次憑證。房間內有限制請求頻率及未認證連線數，但**尚無跨房間、按來源的伺服器端速率限制，不可公開部署**。房主拒絕、邀請被撤銷及未登入／網路錯誤需要更多端到端測試。以房間碼核准後，舊的邀請憑證會失效，需重新產生邀請。
- 邀請連結的高熵憑證位於 URL fragment，讀取後立即從目前網址移除；不記錄 SDP、憑證或房間碼至 Analytics。QR Code 由隨頁 MIT 授權套件在本機產生，沒有外部 QR 服務。邀請憑證仍會交給使用者主動選擇的分享管道，應只分享給可信任的人。
- 原型頁面內的服務端點預設為空，故正式站不會連到任何新服務；只有測試程式臨時提供本機端點。正式 Cloudflare 服務綁定及入口切換需要使用者另行授權。
- `scripts/test-friend-ui-v161.mjs` 測試繁中／日文、手機模擬橫直向及桌面佈局，並解碼本機 QR 與檢查網址片段清理；此 UI 測試使用 WebSocket 替身，**不表示 RTC 通過**。`scripts/smoke-signaling-session-v161.mjs` 不使用替身，安排真正 RTC 完整桌球及同一連線切換其他四種即時模式；結果以最新提交的 GitHub Actions 為準。
- 目前仍未提供玩家資料完整顯示、完整錯誤與中斷恢復、正式無障礙審查、長時間／背景切換、全部遊戲的完整對局或真機驗收。Canvas QR 只由自動程式解碼，手機實際掃描尚待人工。
