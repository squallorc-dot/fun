> 開發發包／逐項勾核用。**全部預設未驗收**，有程式雛形不等於完成。

2026-10-25 最新工程里程碑：`V-01`–`V-06`、`V-08`、`G01-02`–`G01-06`、`G02-03` 的本輪實作與證據，見 [七英雄逐格動畫與戰鬥整合](14_七英雄逐格動畫與戰鬥整合_20261025.md)。這些工作已可執行、已具自動測試；涉及最終視覺／手感的工作仍標為「待人工驗收」，沒有把整份 105 項發包清單改標完成。

## 優先層級與定義

- **P0**：六款一起上線前不可缺少。任何未完成都禁止正式公開。
- **P1**：整體品質與內容深度要求；如影響使用者可玩性也應升為 P0。不得為趕發布省略基本戰鬥動畫與遊戲公平性。
- 狀態欄建議：`待辦`／`進行中`／`阻塞`／`待驗收`／`已完成`；完成前須附 commit SHA、測試記錄、人工驗收結果。
- ID 保持固定不重排，可由主對話框改為 GitHub Issues／Projects，但不得遺漏驗收條件。
- 核心順序：`B → P/A/S → V/G01–G06 → Q → R`。引擎修復與共用系統可以平行，但**發布必須等全部 Q/R Gate**。
