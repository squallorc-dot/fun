# 守護者聯盟全站七選單與 UI/UX 整合

版本：20261025.7。接續基準為 main `7c67bfd5302bfee98d699a33bbe316e827bc0f28`，保留六款遊戲、七組英雄、場景／怪物圖集與四首指定 OST。依本次使用者指示完成設計、整合與正式發布；不沿用舊 RC 文件的再次批准門檻。

## 導覽

- 七個主選單：首頁、世界觀、英雄圖鑑、核心故事、原創音樂、遊戲與互動、創作與應用。
- 桌機大於 1100px：品牌、完整七選單、語言切換。
- 手機／平板不大於 1100px：頂部品牌與語言；底部「首頁、英雄、遊戲、探索」。探索以原生 dialog 呈現其餘四頁，支援 Escape、焦點回復、背景點擊關閉及目前頁面提示。
- 14 個內容頁及 2 個 Arcade 大廳由共用 shell 生成。開始遊戲、選角、說明與音樂設定時處理導覽、捲動與焦點狀態。

## 頁面

- 首頁：主標、動畫與遊戲入口比例調整，使用已完成的遊戲中心封面。
- 世界觀：增加生命之城全景與章節入口。
- 英雄圖鑑：七英雄快捷定位與帶入遊戲的連結，保留商品名稱、功效與商品頁。
- 核心故事：主動畫、四幕故事與延伸影音的導覽，調整閱讀寬度。
- 原創音樂：四首曲目、中文／日文歌詞入口與懶載入音訊，保留歌詞及來源。
- 遊戲與互動：六款遊戲各自開啟準備畫面，舊防衛戰收合保留，八題決策分析保留。
- 創作與應用：統一內容導覽、章節間距與手機排版。
- Arcade：沿用同一網站選單；遊戲模式保留原來的專用全畫面工具與觸控按鍵。音樂面板補齊焦點、Escape、背景停用。
