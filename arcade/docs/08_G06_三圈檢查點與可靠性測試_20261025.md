# Bio-City Arcade｜G06 極速競賽：三圈與檢查點修復紀錄

分支：`development/bio-city-arcade-six-games`。正式 `main` 不變。

## 本次修復

- 原本僅以 `progress >= 3600` 判勝、HUD 按距離顯示圈數，缺乏檢查點。現改為每圈 400／800／1200 三個位置，三圈共九個依序判定的關卡。
- 玩家偏離賽道（橫向距離 > 0.93）試圖通過時，進度停在檢查點前，必須返回有效區域才可繼續；不能直接跳過或只靠里程數獲勝。
- 戰場顯示 CP 計數、分段場景名稱、檢查點地面線與偏離提示。新增分段道路曲率與背景層次。
- `start()` 重設遊戲時間、檢查點及已結算旗標，以支援重試。提供唯讀 `inspectRace()` 供無介面測試。
- 中日文大廳更新 G03 下穿平台與 G06 檢查點操作說明。
