| 過期啟動 | 非同步資源回來後可能接續舊流程 | 兩引擎均使用啟動世代檢查；已離開或被新 session 取代的載入結果不會把舊遊戲帶回來 |
| 連續 OST | 已有遊戲優先協調 | 保留原曲及模式，補背景分頁暫停、可取消播放的錯誤處理；遊戲音樂與連續 OST 維持單一播放權 |

開始音樂的動作在任何素材 await 之前執行，避免等待網路後失去 START 的瀏覽器使用者啟用時機。音效使用既有 Web Audio 合成器，沒有新增或替換音樂／音效檔。

中日文 G02 包裝頁共用 shooter-bridge.js；同樣處理來源驗證、ready／start、章節、音效、暫停與恢復訊息。主站內嵌舊射擊入口也同步載入音效政策及 session-runtime，避免只改 Arcade 新入口。

## 保存與回歸保護

- 新玩家 BGM 40%、SFX 55%；既有設定沿用 audio-policy 版本 2，不新增重置遷移。
- 保留每關隨機、場景推薦、自選、關閉、循環與開始時播放；操作／恢復不自行改音量。
- 五章進度、G05 兩模式、七英雄能力、最高分及既有儲存 key 均不變。
- games-core.js、碰撞、賽道幾何、動畫圖集、背景及四首 MP3 均未改動。
- 手機「遊戲模式／闖關進度」維持分列，「連續闖關」保持無括號五章。
- 不以降低動畫、刪除場景物件或修改難度作為本批穩定性修正。

## 驗證

本機 19／19 指令成功：3 個建置／結構檢查、原有 15 組引擎回歸及新增 session 測試。完整命令、耗時、stdout／stderr 見 [原始結果](v1.4/batch-1-test-results.json)。

新增 Node 測試涵蓋 3 秒保護、倒數取消／重開、tick 中取消、素材失敗／逾時、圖片解碼等待、失敗圖片重新請求。時間與圖片案例是明確控制的測試，不是裝置效能測量。

新增真實 Chromium 互動測試涵蓋：

- 中日文、桌機、手機直向及橫向；延遲必要背景時不先啟動，音樂仍可在 START 開始。
- 載入期間轉背景、返回仍暫停、倒數凍結世界、再次轉背景取消、退出後倒數不復活。
- 真實圖片 HTTP 失敗與重新請求；離開期間晚到的載入結果不重新開遊戲。
- 明確注入 NotAllowedError 的受阻情境，及真實音訊 HTTP 失敗；確認入口、診斷與重試後的實際 MP3 播放。
- G02 已存 SFX 23% 的沿用、靜音往返、BGM 設定保存、多指射擊 owner、lostpointercapture、blur 清理及恢復倒數。
- 連續 OST 的背景暫停、遊戲讓出與退出後恢復。

既有瀏覽器測試更新為等待真正完成倒數，保留原有 RAF、focus、操作及保存斷言；未跳過倒數、縮短產品倒數或關閉動畫來讓測試過關。完整 GitHub Actions 瀏覽器結果及發布 SHA 在合併前核對。

## 驗收界線與後續

Windows Chrome／Edge 的原始不播放回報尚未在相同作業系統重現；本批提供恢復入口、設定辨識與可檢查狀態，不能把 Chromium 自動測試或注入錯誤當成 Windows 根因證明。

實體 iPhone／Android：**等待真機驗收**。直橫及手機寬度的瀏覽器測試是 viewport 測試，不能稱為真機通過。六款各五章的完整合法通關、公平性與長時效能仍屬後續批次，不由本批測試取代。

下一主要批次為第 2 批操作配置／搖桿人體工學；低幀率時間問題留在第 3 批，Canvas／素材解析度與場景統一留在第 4 批。
