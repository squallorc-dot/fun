# Bio-City Arcade｜G04 能源彈珠競技三關制（2026-10-25）

## 本輪實際程式修改

- G04 不再只顯示單一靶場；現有原始玩法升級為三段：**ENERGY LAB**（四個目標、兩個反彈器）、**REFLECTION GRID**（六個目標、三個反彈器，其中一個目標兩層耐久）、**CORE BREAKER**（八個目標、四個反彈器，含三層核心目標）。
- 每關按一般／進階／專家設定射擊彈數；完成前一關保留累積分數，補給下一關彈數並更換場地。
- 只有第三關全部目標歸零才算整體勝利；無彈可用且無移動彈珠時直接失敗並標明關卡。
- 統一固定 120 Hz 的碰撞時間步長，瞄準、力道、牆壁、反彈器保持原操作；補入同一彈珠對同一目標的入侵鎖避免每格重覆扣耐久。
- 加入三關各自配色、關卡名稱、HUD 進度及短暫換關提示；中日文大廳說明同步更新。
- 重新挑戰清空關卡、時間、彈數、目標耐久、物理債務、得分與終局狀態。

## 具體測試與界限

- `node scripts/test-g04-stages.cjs`：三難度 × 三畫布尺寸共 9 組，驗證真實射擊擊中第一關中央目標、三關轉換、耐久不同、最終獲勝、重玩還原；另測第一關彈盡失敗，及 120/30/20 FPS 模擬一致性。
- `node scripts/test-arcade-replay.cjs`：同步修改舊單關發射數值假設，仍測三難度的重玩／旋轉與球類比數。
- 原有六款基本終局、G01 格鬥、G05 球類、G06 賽車回歸不應因更新失敗，新增測試加入 GitHub Actions arcade-engines 工作。
