# 遊戲接地、賽道遮擋、手機選單與 OST 修復

日期：2026-10-26。基準：main `7f15deb5c6b91e4dbbc1dcfed098bf415b0ae815`。

## 第一階段：手機介面與音樂

- 窄於 580px 時，「遊戲模式」「闖關進度」各占一行；選單採 16px 字級、48px 高度。
- 「連續闖關（五章）」縮為「連續闖關」；章節選項為「第 N 章」，總章數與解鎖資訊移至說明。
- 初次設定改為每關隨機，前後兩次啟動不重複歌曲；沿用四首既有遊戲 OST。
- 舊版自動場景預設移轉為隨機；既有手動選曲、關閉配樂、零音量與關閉自動播放設定保留。本版明確選擇場景模式後也會保存。
- 在開始遊戲的點擊流程先要求播放，再建立遊戲。狀態依實際 media 事件顯示；區分播放限制與載入錯誤，忽略切歌取消的過期請求。
- 離開遊戲停止遊戲配樂；連續 OST 模式會恢復原曲。背景分頁暫停後，使用繼續按鈕恢復原本正在播放的遊戲音樂。

## 第二、三階段：賽車

- 車體改為後方視角，輪胎底端與接觸陰影共用路面座標。
- 道路多邊形先在鏡頭空間裁切，再投影；鏡頭跟隨所在地形斜率，避免陡坡造成近處道路反轉。
- 地形、道路、護欄、路旁物件、障礙及對手依道路區段與距離繪製；以近處坡頂遮擋遠處景物。
- 地形側面沿道路實際邊緣填色，路面接縫補齊；瀝青使用實心中性深色。
- 路旁物件的完整寬度與護欄保留至少 0.75 世界單位的間距，涵蓋樹冠、岩塊與指示牌。
- 桌機與手機橫向使用 960 × 540 寬畫布，直向保留 640 × 800；旋轉沿用同一局的進度與物理狀態。
- 五章各有城市、山林、高架、峽谷與核心區的遠景和物件；天空與雲層具動態，景物隨路線方向、位置與速度變化。
- 轉向側移以實際路線曲率計算；加入煞車／路肩揚塵、氮氣尾焰及高速流線。保留三圈／檢查點、超車、尾流、耐久及重試規則。

## 第四階段：其餘五款

- 格鬥：接地陰影隨跳躍高度縮小；落地加入地面波紋。
- 城市防衛：角色、敵人與 Boss 依腳底位置排序並加入接觸陰影；敵人受擊、施法與迴避使用各自動作時鐘，修正非循環動畫直接停在最後一格的情形。加入槍口閃光與敵方彈體拖影。
- 平台：影子落在實際可支撐的平台，無支撐面時不畫空中接觸影；增加落地、補給、平台碎裂效果及平台厚度／移動導軌。
- 彈珠：實際球路拖影、碰撞閃光、目標破壞碎片、球體高光與機件陰影；移除重複章節文字。
- 排球／桌球：角色影子與球場接地，排球影子留在地面；加入實際球路拖影、回球／落桌效果及得分提示；桌球對手顯示移動與揮拍動作。
- 第一章起就有低強度場景動態：遠處交通、能源訊號、井道流動、實驗室機構與球場燈光。裝飾不改變碰撞幾何。

## 已執行驗證

- `node scripts/build.mjs --check`、`verify.mjs`、`verify-arcade.mjs` 通過。
- 15 組 Node 回歸通過：引擎、可靠性、格鬥判定、七英雄技能、逐格動畫、重玩、戰役、五章、桌球、排球、英雄圖集、彈珠關卡、音樂偏好、接地陰影、賽車。
- 賽車新增五章共 1,000 個位置的近處道路、輪胎位置、路旁間距及有限投影座標檢查。
- 既有賽車 108 組三圈完整模擬、360 個鏡頭位置，以及停車、對手移動、碰撞、超車與重試檢查通過。
- 雲端 Chrome 實際操作六款／七模式；配樂 `currentTime` 前進、相鄰遊戲曲目不同。直接進入與連續 OST iframe 均確認實際播放；遊戲時連續 OST 暫停，返回大廳後恢復。
- 已檢視五章賽道代表位置、320px／390px 選單，以及繁中／日文入口。完整多尺寸與中日文瀏覽器回歸納入 GitHub Actions。

## 驗收界線

本次完成的是接地、遮擋、動態回饋與音樂修復，沿用既有角色圖集及場景素材。尚未製作六款 × 五章的 30 套全新獨立美術，亦未以瀏覽器手機尺寸模擬代替實體 iPhone／Android 觸控與音訊驗收。
