# Bio-City Arcade｜G01 守護者大亂鬥・即時戰鬥手感修正

日期：2026-10-25
分支：`development/bio-city-arcade-six-games`
狀態：**開發修正／待瀏覽器與真機真人驗收；不等於完整格鬥遊戲完成**。

## 變更

1. 攻擊在當次輸入先更新朝向後判定；三段連擊分段傷害、距離、命中火花、受擊硬直與輕量 hit-stop。
2. 防禦閃避現在能在未按移動方向的情況下朝上次面向衝刺，並具短暫無敵時間與冷卻；跳躍亦可避開部分近地攻擊。
3. 遠程敵人的攻擊不再在發動時直接扣玩家血量；改成可看見、可走位及閃避的彈體，具有生命週期、命中判定及特效。
4. Boss 分為「地面震波」與「三向能量彈」，施放前有瞄準警示、前搖與命中範圍，並可用移動／閃避／跳躍應對。
5. 當玩家命中敵人時取消其當次攻擊蓄力，並補充技能清彈、擊中效果、能量與 HUD 提示。
6. 遊戲重新開始時重設敵人、彈體、特效、分數、回合、玩家攻擊狀態與結算旗標。
7. 增加唯有測試模式可啟用的場景準備 API，用於精準重現特殊事件與勝負判定；一般玩家不會啟用。

## 可重現測試

```bash
node scripts/test-g01-combat.cjs
node scripts/test-arcade-engines.cjs
node scripts/smoke-arcade.mjs
```

`test-g01-combat.cjs` 在 normal / hard / expert 皆檢查：三段命中、累積傷害、前搖、真正位移的遠程彈體、閃避無敵、Boss 警示、擊敗 Boss、玩家敗北、相同實例重開重設；本地 Node 測試均通過。

**重要限制：** 本機回歸副本的 G05 仍是較早、未合入上次排球終局修復的版本，因此直接跑該副本的 `test-arcade-engines.cjs` 會在 G05 中斷；這不代表最新開發分支的 G05 又故障。此次只會將 G01 模組嵌入 GitHub 最新 `games-core.js`，並交給 GitHub Actions 在最新分支上執行六款整合測試、跨語系瀏覽器測試。不可把舊副本的執行結果宣稱為最新分支結果。
