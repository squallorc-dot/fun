# Bio-City Arcade 場景、怪物、賽道與觸控更新

本次針對上一版幾何角色、空白背景、寬螢幕遊戲距離與泛用八鍵介面進行更新。六款遊戲共用固定邏輯尺寸，在視窗中等比例縮放；換螢幕或旋轉不再把遊戲世界拉寬。指標輸入同步轉換為遊戲座標。

## 實際遊玩變更

| 遊戲 | 場景與玩法 | 手機操作 |
| --- | --- | --- |
| G01 | 新城市街道；孢子爬獸、鐵殼破壞者、裂隙幽靈、熵核巨獸四組動畫敵人。 | 十字方向鍵；攻擊、跳躍、閃避、技能分區。 |
| G02 | 新俯視城市廣場；同四種敵人圖集接入射擊引擎，保留三波、七英雄與 Boss。 | 左側類比搖桿，右側射擊、閃避、技能；自動瞄準。 |
| G03 | 深井背景、立體平台、裂紋、陷阱與綠色回血補給。向下每次僅穿過目前平台。連續墜落過長會受傷，踩平台重置墜落距離，避免沿邊緣直接落到底過關。 | 左右移動；另一側向下與跳躍。 |
| G04 | 能源實驗室背景、三關碰撞靶場；新增收球重新瞄準，已用彈數不退還。 | 十字鍵調角度與力道；發射、收球。 |
| G05 | 運動場背景；排球與桌球分別使用各自的場地、規則及操作。保留先前降低球網和雙方發球軌跡修正。 | 排球左右、擊球、跳躍；桌球上下與揮拍。 |
| G06 | 封閉城市賽道、彎道與坡度、五輛各自前進的對手、超車加分、尾流回復、九個檢查點、真實路線小地圖。 | 左右轉向；煞車可完全停車、氮氣加速。車輛自動前進。 |

G06 的車輛距離、道路、對手、障礙與檢查點共用同一套世界座標和透視投影。煞車停住後，玩家里程與道路投影不再變動，對手仍持續前進。這是擬 3D 街機賽車，並非寫實物理模擬器。

## 顯示與效能

- 邏輯尺寸：G01 800×600、G02 600×600、G03 480×720、G04 600×720、G05 640×480、G06 640×800。
- 縮放與 DPR 上限 2；尺寸更新改由 ResizeObserver 觸發，移除逐幀量測版面。
- HUD 最多每 100ms 更新，射擊物理分步執行；背景最多保留三張、角色最多保留五組圖集。
- 觸控按鍵依玩法顯示，最小有效目標 44px；橫向手機把按鍵留在兩側，避免遮擋中央遊戲區。
- 大廳保留大型選單及七組選角，六張遊戲封面重新擷取實際遊戲畫面，直式畫面完整顯示。
- Arcade 音樂僅四首指定版本，舊六首清單的失效偏好會自動遷移。

## 驗證方式

引擎測試涵蓋 G01 七英雄技能、781 格動畫、G03 900 張隨機平台、長按下樓、G04 三關與收球、G05 630 場比賽及 144 組雙方發球／72 組站立回擊、G06 108 場三圈比賽及停車／超車／碰撞／封閉路線與 360 組鏡頭位置。瀏覽器測試涵蓋兩語系、五種視窗、觸控與桌面、六款共七種模式、場景實際解碼、按鍵尺寸與互不重疊。

`scripts/capture-arcade-visual.mjs` 產生兩語系的桌面、手機及操作說明截圖；CI 將完整截圖存為 `bio-city-arcade-rc-screenshots` 工作流程附件。這些為瀏覽器模擬驗證，實體 iPhone／Android 的觸控、音訊與最終手感仍需實機確認。

素材與生成提示見 [場景素材紀錄](../assets/worlds/README.md)。
