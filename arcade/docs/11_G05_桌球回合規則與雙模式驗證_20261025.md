# Bio-City Arcade｜G05 桌球玩法升級與回歸驗收（2026-10-25）

狀態：開發分支候選，非正式上線。

## 修改
- 原本 Pong 直線牆壁反彈模式更新為俯視桌球：球桌、球網、桌面陰影、獨立球拍、彈跳高度、發球方先落台、過網後對方回球、二跳得分、側邊出界／觸網失分。
- 桌球輸入：W/S 或上下方向鍵移動球拍；J 或 Space 在球接近拍面時擊球；電腦 AI 隨難度調整速度與失誤。
- 為桌球加入固定 1/120 秒物理步長與每回合 18 秒上限，低 FPS 仍可結算。
- 排球維持獨立模式，仍使用原重力與觸球邏輯。切換模式使用原 G05 選單。
- 保留原先 G05 本機成績名稱與 mode=pong 的向下相容鍵，畫面呈現改為 TABLE TENNIS。
