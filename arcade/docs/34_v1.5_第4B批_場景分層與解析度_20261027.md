## 四種模糊原因分開處理

1. **原生解析度不足**：六張背景最大邊只有 1,280 px，repo 無較大的原 PNG／分層原稿。背景保持原檔，沒有插值「補細節」。七英雄有 `scripts/build-guardian-art.cjs` 向量原稿，實際重製了 320×320 單格、71 格／英雄的 2x PNG。
2. **CSS／Canvas 拉伸**：舊 backing store 只看邏輯尺寸乘 DPR，桌機放大後像素供應不足。現在依實際顯示倍率、DPR，以 0.25 級距配置，保留原最低密度、最高 4 倍邏輯尺寸；不改世界大小。Canvas 邊框改為不佔內容尺寸的 outline，避免邊框擠壓比例。極高 DPR／超出測試尺寸仍受上限限制。
3. **構圖／透視**：G02 改用俯視周邊模組；G01 地面沿用原圖消失點；G06 天空不再包含不相容的交通通路，互動道路完全沿用世界投影；G05 視角未變。
4. **前後層錯誤**：地面、接觸影、依深度排序的物件、近角前景、危險邊線與特效／HUD 有明確次序。跳躍陰影仍錨定支撐面，無支撐自由落下不新增浮空接觸影。

六款實際 CSS 尺寸、DPR、backing store、來源尺寸、採樣倍率、資源傳輸大小與本機載入時間，見 [量測 JSON](v1.5/batch4b-art-20261027.json)。瀏覽器為本機靜態 HTTP、系統 Chromium；載入時間不代表正式 CDN 或實機速度。來源圖的 `coverScaleDevice > 1` 表示仍有來源放大，不代表已取得高解析背景。G06 使用局部天空裁切，G03 使用寬度配適捲動，量測亦標註其映射差異。

## 素材與效能

原背景 WebP、原版圖集與其雜湊全部保留。新增圖集直接以 SVG、Sharp 0.35.5／libvips 8.18.7 的 density 144 柵格化（原版 72），並提高色盤採樣至 256 色；不是放大既有 PNG。重製：

```sh
node scripts/build-guardian-art.cjs --high-resolution
node scripts/test-arcade-art.cjs
```

一般建置／CI 不需安裝 Sharp。2x 圖集有尺寸、大小及 SHA-256 manifest；來源與既有原創向量相同，未新增外部圖像、字型或音樂。G01 的 DPR > 1 選用一張當前英雄 2x；其餘遊戲及敵人不額外下載。最多一張 2x 加四張原版，56.25 MiB 解碼像素；原背景仍最多三張、離屏 raster 仍為 16 MiB，超大 raster 使用原有直接繪製路徑。2x 載入／解碼失敗改讀原版；必要原版也失敗仍使用既有重試介面。版本更新涵蓋中日文主頁、遊玩頁及 G02 iframe 的實際腳本。

## 驗證與待驗收

測試結果與 CI 連結會列於本 PR；包含建置同步、既有二十套 Node 與新增素材測試、G02 裝置公平性、G06 120 場矩陣及 108 場舊競速測試、完整中日文瀏覽器／操作／OST／存檔／低幀率回歸。所有舊品質門檻保留。

尚未完成的是六張背景的真正高解析重製、敵人較高解析版及角色新增美術細節；需要合法原始 PNG／分層原稿，或另行授權重新製作，建議背景長邊至少 2560～3840、包含可分離遠中前景，G03 提供可無縫接合的上下邊，G06 不含道路的天空／遠景分層。此批未啟用任何付費素材服務。

Chromium 的桌機／手機模擬不等於實機通過。仍待 iPhone／Android 檢查安全區、轉向、多指輸入、真實幀率及長時間解碼記憶體；Windows Chrome／Edge 檢查不同縮放倍率、畫面清晰度、GPU 表現與 OST 音量／自動播放。完成本批後停止，不啟動玩法重構、美術全面重製或好友連線。
