## 發布檢查與限制

原六項 GitHub Actions 必須在整合候選 HEAD 全部成功；具體結果及 Commit 以候選 PR Checks 為準。人工的 Windows、iPhone／Android、兩台不同實體設備同 LAN、背景切換、觸控與真人體驗均**待驗收**。無 STUN／TURN 與外部信令，僅能以已驗證的同網路情境為基礎，不能保證跨網路連線。G06 客戶端目前直接套用快照，尚未平滑插值；G02 快照超過安全上限會停止連線，取樣最大值不構成理論上限。

正式遊戲中心維持六款單人入口；繁中／日文首頁新增同站好友大廳入口。好友大廳和挑戰頁不載入 GTM；自動瀏覽器測試阻擋外部請求，G02 合作不送單人開始／完成事件或寫入單人最高分。仍須在部署授權後核對正式 GTM／GA4 規則，不能以原始碼檢查宣稱正式資料已經驗證。更新靜態資源版本以避免舊快取混用。
